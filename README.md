## Projects

## How I work

I write down the design before I build. When something breaks, I find the cause and put something in place so it doesn't happen again. Kaizen, basically.

## On AI

I build with AI: Claude for planning and reverse engineering, Cursor for implementation. I couldn't do this without it. I review and test what I publish, and I'm still learning good and safe practices. If you find something wrong, open an issue.

## What I don't publish

Game binaries, assets, decompiled code, or anything a developer chose to obfuscate. Fixes ship as patches that need your own copy of the game.
