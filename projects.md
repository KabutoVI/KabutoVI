# Projects

Everything I'm working on in public, in one place. I update this as things move.

None of these include game binaries, assets or decompiled code. Fixes ship as source or patches that need your own copy of the game.

## My projects

| Project | What it is | Status |
| --- | --- | --- |
| [REA Lab toolkit](https://github.com/KabutoVI/rea-lab-toolkit) | The scripts I use to take software apart: headless Ghidra scripts, PE and .NET helpers, a log redactor, a small dashboard, and a local-model function labeler that only keeps labels backed by a real quote from the code | Early prototype |
| [TACTICAL Covenant vs UNSC](https://github.com/KabutoVI/covenant-command) | A game mode for Project Reclaimer (Halo 3 on PC) that tries to make the Covenant more fun to play. Squads, a bigger reinforcement pool, earned vehicles. The UNSC side hasn't been started | Early prototype |
| [Panzers widescreen fix](https://github.com/KabutoVI/panzers-widescreen-fix) | A tiny d3d9 proxy that adds widescreen resolutions and a borderless window to Codename: Panzers - Phase One. It patches the game in memory, so the files on disk stay untouched | Working |
| [Sparta widescreen fix](https://github.com/KabutoVI/sparta-widescreen-fix) | A d3d9 proxy that fixes the menu layout at 1440p in Sparta: Ancient Wars and lets you shrink the in-game HUD | Working in testing, not everything checked |
